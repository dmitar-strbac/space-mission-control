# 🛰️ Vehicle Service

The Vehicle Service manages spacecraft configuration, validates onboard resources and ensures vehicle readiness before mission execution.

## Responsibilities

- Spacecraft configuration management
- Vehicle availability validation
- Resource verification
- Propellant validation
- Oxygen validation
- Power system validation

## Technology

- Python
- FastAPI
- PostgreSQL
- NATS

## Default Port

8002

## Database

PostgreSQL

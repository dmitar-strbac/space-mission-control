# 🌍 Trajectory Service

The Trajectory Service is responsible for planning orbital trajectories and generating spacecraft maneuvers based on mission objectives.

## Responsibilities

- Trajectory planning
- Launch window evaluation
- Maneuver generation
- Trajectory feasibility validation
- Trajectory recalculation

## Technology

- Python
- FastAPI
- PostgreSQL
- NumPy
- SciPy

## Default Port

8003

## Database

PostgreSQL

# 📈 Telemetry & Safety Service

The Telemetry & Safety Service processes spacecraft telemetry, detects anomalies and delivers real-time mission updates to operators.

## Responsibilities

- Telemetry processing
- Anomaly detection
- Safety alerts
- Abort recommendations
- Real-time WebSocket communication

## Technology

- Python
- FastAPI
- MongoDB
- WebSocket
- NATS

## Default Port

8006

## Database

MongoDB

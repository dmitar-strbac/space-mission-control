# 🛰️ Flight Dynamics Service

The Flight Dynamics Service performs the physical simulation of spacecraft motion using simplified but physically consistent orbital mechanics.

## Responsibilities

- Orbital state propagation
- Gravitational acceleration calculations
- Orbital maneuver execution
- Spacecraft mass updates
- Propellant consumption
- Simulation state generation

## Technology

- Python
- FastAPI
- PostgreSQL
- NumPy
- SciPy

## Default Port

8004

## Database

PostgreSQL
